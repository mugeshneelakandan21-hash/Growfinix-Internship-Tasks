# Real Estate Exploratory Data Analysis (EDA)

## Objective
Analyze a real estate dataset by cleaning missing values, identifying and handling outliers, and visualizing house prices across neighborhoods and property sizes.

## Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed
1. Inspected the dataset
2. Identified missing values
3. Filled missing area values using the median
4. Detected price outliers using the IQR method
5. Removed extreme price outliers
6. Created a house price distribution
7. Compared prices across neighborhoods
8. Analyzed the relationship between property size and price
9. Compared average prices by neighborhood

## Visualizations
- House Price Distribution
- Price Distribution Across Neighborhoods
- Price vs Property Size
- Average House Price by Neighborhood

## Conclusion
The analysis demonstrates how data cleaning and exploratory visualization can be used to understand real estate price patterns and relationships between property characteristics and prices.
